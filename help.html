How ShopList works

ShopList is a simple shopping-list app for creating grocery lists, organizing reusable templates, managing item categories, and keeping track of favorite stores. You can build lists from scratch, add items manually, or start from a saved template to speed things up.

My Lists

My Lists is where your active shopping lists live. Create a list, give it a name and optional description, choose one or more stores, and then add the items you want to buy.

  • Use New List to create a fresh shopping list.
  • Open a list to add items, notes, quantities, units, stores, and categories.
  • Mark items complete as you shop to track progress.

Templates

Templates help you save common groups of items, such as weekly groceries, party supplies, or holiday shopping staples. They are useful when you buy the same things often.

  • Create a template once and reuse it anytime.
  • Add a template directly into an existing list or a new one.
  • Use templates to avoid retyping recurring items.

Categories

Categories help organize items into groups like Produce, Dairy, Frozen, or Bakery. This makes lists easier to scan and manage.

  • Create your own categories with names and emojis.
  • Assign categories to items for better organization.
  • Review which template and list items belong to each category.

Stores

Stores let you save the places where you shop most often. You can connect items, templates, and lists to one or more stores.

  • Save favorite stores with a name and emoji.
  • Tag items or lists to one or more stores.
  • Review which items are connected to each store.

Settings

Settings contains your profile, appearance options, and data tools. It is also where you can export or import your data and sign out of the app.

  • Switch between light and dark mode.
  • Export your data for backup.
  • Import saved data when needed.

Best way to use it

A simple workflow is to create your stores and categories first, then build templates for repeated shopping, and finally create active lists from scratch or from those templates.

  • Set up stores and categories one time.
  • Build templates for repeat trips.
  • Create a fresh list each week and check items off as you shop.

Tip: if you shop at the same places every week, combining templates with store tags can make list creation much faster.
