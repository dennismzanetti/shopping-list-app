What this migration does

  • ③ Copies users/{uid}/templates/{id} → templates/{id} with ownerId + visibility
  • ④ Backfills any top-level lists/ docs (owned by you) missing ownerId, ownerName, or visibility
  • ⑤ Backfills any top-level templates/ docs (owned by you) missing those fields
